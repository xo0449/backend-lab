# 모듈 작성 규약

모듈 하나는 폴더 하나입니다. 등록 절차는 없습니다.
웹이 이 폴더를 읽어 목록을 만듭니다.

## 필수 파일

- `meta.json` — 웹이 읽는 메타데이터
- `README.md` — 고민, 접근, 결과, 다시 한다면

## README 형식

### 고민
무엇이 문제였나. 왜 이게 어려운가.

### 접근
무엇을 했나. 왜 그 방법이었나.

### 결과
실험이면 측정 전후. 구현이면 내린 결정과 이유.

### 다시 한다면
바꿀 부분.

## 규칙

`meta.json`의 `question`은 비울 수 없습니다.
실험은 `metrics`가, 구현은 `decisions`가 있어야 합니다.
검증은 `shared/module-meta.ts`에 있고, 웹 빌드가 이를 확인합니다.
